# Бот-трекер привычек с напоминаниями

Freemium-бот: бесплатно до 3 привычек, Premium (оплата в Telegram Stars — прямо внутри Telegram, без внешних платёжных систем) снимает лимит и открывает гибкое время напоминаний.

## 1. Получить токен бота

1. Открой в Telegram **@BotFather**
2. Отправь `/newbot`, придумай имя и username (должен заканчиваться на `bot`)
3. Скопируй токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

## 2. Включить приём Stars (для монетизации)

Telegram Stars включены по умолчанию для всех ботов — отдельно подключать платёжного провайдера не нужно. Всё, что заработаешь, выводится через @BotFather → Bot Settings → Payments.

## 3. Установка и запуск локально

```bash
cd habit_bot
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Укажи токен
export BOT_TOKEN="твой_токен_от_BotFather"   # Windows: set BOT_TOKEN=...

python3 bot.py
```

Бот запустится и будет опрашивать Telegram (polling) — этого достаточно для старта и первых пользователей.

## 4. Как это работает

- `/start` — приветствие и меню
- `/add <название>` — добавить привычку
- `/list` — список привычек со стриками
- `/done <номер>` — отметить выполненной
- `/time <номер> <ЧЧ:ММ>` — время напоминания (Premium)
- `/premium` — выставляет счёт в Stars через `send_invoice`
- Напоминания шлются раз в минуту планировщиком (APScheduler), сверяясь со временем в БД
- Все данные хранятся в `habits.db` (SQLite), создаётся автоматически

## 5. Чтобы бот работал 24/7, а не только пока открыт твой компьютер

Локальный запуск подходит только для теста. Для реальной работы нужен постоянно включённый сервер. Варианты для старта без затрат:
- **Railway.app** / **Render.com** — бесплатный тариф, деплой из GitHub за пару кликов
- **PythonAnywhere** — бесплатный tier, но polling там ограничен
- Дешёвый VPS (от ~$3-5/мес) — самый надёжный вариант в долгую

На любом из них: залей эти 3 файла, укажи `BOT_TOKEN` как переменную окружения, команда запуска `python3 bot.py`.

## 6. Что доработать дальше, когда пойдут первые пользователи

- Часовые пояса пользователей (сейчас время напоминаний в UTC)
- Учёт валюты Stars → реальные деньги привязан к региону, посмотри актуальный курс в @BotFather
- Аналитика: сколько людей доходят до /premium — это твоя конверсия, от неё зависит доход
- Продвижение: тематические Telegram-чаты, охватные каналы, посевы — без этого даже хороший бот не наберёт пользователей сам по себе
